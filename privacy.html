Privacy

Last updated November 11, 2026

The short version

  • Free, with no sign-in. You never need an account to use a RobsonEDU tool.
  • Your class data stays on your device. Class lists, seating charts and settings are saved in your own browser. They are never sent to RobsonEDU.
  • No ads, ever. We don't sell or share data with anyone.
  • We count visits without cookies. We see which pages and tools get used, never who used them or any student information.

Where your class data lives

The tools save what you type in your browser's own storage on the device you're using. RobsonEDU has no server that stores class lists, and we can't see them.

Grouping StudioClass lists, scores and notes you add, rooms, seating charts and groups
SELECTr PLUSClass lists, pick history, tasks and settings
Timer PLUSSettings, routines, alarms and music lists

Because it lives on one device:

  • Your data won't follow you to another computer or browser.
  • Clearing your browser's history or site data erases it.
  • In Grouping Studio, use Download backup about once a month so you always have a copy.

Importing a class list from Google Sheets (optional)

Grouping Studio can import a class list from a Google Sheet. If you use it, you sign in with Google, and Grouping Studio can open only the one file you pick. The list goes straight from Google to your browser; it never passes through a RobsonEDU server. The sign-in lasts only while the page is open. Some districts need IT to approve this first. Copying and pasting from a spreadsheet always works with no sign-in.

What we count

We use Plausible Analytics, a privacy-first visit counter. It uses no cookies and doesn't collect personal information. It helps us see which tools teachers use most, so we know what to improve.

We count: page visits, the website a visitor came from, the general type of device and country, and a few actions: making a seating chart, opening Present view, spinning SELECTr, starting a timer, opening a printable or PDF, clicking an email link or a link to another website, and sending the contact form.

We never send or see: student names, class names, chart names, class lists, scores or anything else you type into a tool.

Other services some pages use

  • Google Fonts supplies the lettering on many pages.
  • YouTube plays music in Timer PLUS, only if you choose to play some. YouTube's own privacy policy applies to what it plays.
  • Formspree delivers messages you send with the contact form at the bottom of each page.
  • Google Docs hosts some printables, such as the TeamCard table mats.
  • The Colors Personality Assessment loads a small public code library to save your result as an image.

Students

The tools are made for teachers, usually on the classroom display. If students use a tool on their own device, the same rules apply: what they enter stays on that device.
